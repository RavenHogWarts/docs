# 阅读器
[Web Clipper](../) 包括一个名为 `阅读器` 的内置阅读模式，可以消除网页上的混乱，仅以干净、可读的格式呈现主要文章内容。

## 激活阅读模式
您可以通过以下几种方式激活 Reader：
- 扩展面板中的书籍图标 <LucideIcon name="BookOpen" class="inline-icon"/>。
- 键盘快捷键，可在扩展设置中自定义。
- 右键点击正在访问的网页以打开上下文菜单。

您还可以将扩展按钮设置为一键打开 `阅读器`。在 Web Clipper 设置中，前往 `常规` → `行为` → `打开行为` 并选择 `阅读器`。

以上所有选项都允许您退出阅读器并恢复原始页面。

## 工作原理
`阅读器` 从页面中提取主要内容。原始页面被替换为一个干净的阅读视图，包含以下内容：

- 文章标题、作者、发布日期和来源域名。
- 主要文章内容，保留图片和格式。
- 侧边栏中的大纲，适用于具有多个标题的文章。
- 代码块的语法高亮。
- 点击时以内联方式显示的脚注弹出框。

## 自定义阅读界面
您可以在扩展设置中自定义阅读器的使用体验。部分选项也可在阅读模式下通过点击 <LucideIcon name="CaseSensitive" class="inline-icon"/> 图标进行设置。

| 设置       | 描述                       |
| ---------- | -------------------------- |
| 字体       | 添加安装在您系统上的字体。 |
| 字体大小   | 调整文本大小。             |
| 行高       | 行间距。                   |
| 行宽       | 内容区域的最大宽度。       |
| 外观       | 选择浅色或深色外观。       |
| 主题       | 选择颜色。                 |
| 自定义 CSS | 应用于页面的额外 CSS。     |
